# Boaba Coffee

Демо-лендинг для кофейни: первый экран, меню, о нас, отзывы и форма брони столика. Кофейня выдуманная, страница сделана как пример работы.

Обычный HTML, CSS и немного JS, без сборки и библиотек. Открыть `index.html` в браузере.

Форма сейчас только показывает "Спасибо". На реальном сайте заявка уходит владельцу в Telegram или на почту через маленький сервер.
